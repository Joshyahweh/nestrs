## `IdempotencyModule::register`

Exports `IdempotencyOptions` (`TypeId`).

## `IdempotencyOptions`

| Field | Type | Notes |
|-------|------|-------|
| `store` | `SharedIdempotencyStore` | Memory or Redis |
| `header_name` | `String` | Default `idempotency-key` |
| `required` | `bool` | Missing key → 400 |
| `scope` | `Option<String>` | Prefixed into store key |

Helpers: `IdempotencyOptions::default()`, `::in_memory(ttl)`.

## `idempotency_middleware`

```rust
pub async fn idempotency_middleware(
    State(opts): State<Arc<IdempotencyOptions>>,
    req: Request,
    next: Next,
) -> Response
```

Replay header: `idempotency-replayed: true`. In-flight: **409** `IDEMPOTENCY_IN_FLIGHT`.
