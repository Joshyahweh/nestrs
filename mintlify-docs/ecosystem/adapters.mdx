---
title: "Adapter crates (NestJS ecosystem analogues)"
description: "Companion crates that close NestJS gaps nestrs cannot fold into Axum: Socket.IO, Lambda, Passport, Better Auth, BullMQ, SAML, LDAP, and SeaORM."
---

Wave 9 ships these as **workspace crates**, not umbrella `nestrs` features. Depend on them directly. They target `nestrs-core` (or nothing) so they do not create a cycle with the façade crate. Fastify remains out of scope ([ADR-0001](https://github.com/Joshyahweh/nestrs/blob/main/docs/src/adrs/0001-axum-only.md)). `nestrs-drizzle` stays carved out of workspace members.

| NestJS | Crate | What you get |
|--------|--------|----------------|
| `@nestjs/platform-socket.io` | [`nestrs-socketio`](https://docs.rs/nestrs-socketio) | socketioxide layer + `merge_socketio` |
| AWS Lambda / serverless | [`nestrs-lambda`](https://docs.rs/nestrs-lambda) | `listen_lambda(router)` (API Gateway HTTP + REST) |
| `@nestjs/passport` | [`nestrs-passport`](https://docs.rs/nestrs-passport) | `JwtStrategy` / `LocalBasicStrategy` on `AuthStrategy` |
| nestjs-better-auth | [`nestrs-better-auth`](https://docs.rs/nestrs-better-auth) | nest the better-auth.rs Axum router + `BetterAuthGuard` |
| `@nestjs/bullmq` | [`nestrs-bullmq`](https://docs.rs/nestrs-bullmq) | BullMQ Redis key-layout producer (Node workers can consume) |
| `passport-saml` | [`nestrs-saml`](https://docs.rs/nestrs-saml) | SP-initiated redirect + `SamlResponseValidator` trait |
| `passport-ldap` | [`nestrs-ldap`](https://docs.rs/nestrs-ldap) | LDAP simple bind |
| TypeORM / Sequelize | [`nestrs-sea-orm`](https://docs.rs/nestrs-sea-orm) | `SeaOrmModule::for_root_async` |

```toml
[dependencies]
nestrs-socketio = "1.3.0"
nestrs-lambda = "1.3.0"
nestrs-passport = "1.3.0"
nestrs-better-auth = "1.3.0"
nestrs-bullmq = "1.3.0"
nestrs-saml = "1.3.0"
nestrs-ldap = "1.3.0"
nestrs-sea-orm = "1.3.0"
```
